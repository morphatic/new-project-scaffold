# plinth/

The foundation of this project. Holds agent-facing context — planning and research — that informs work on the scaffold without belonging in the templates themselves.

Named after the architectural plinth (the base a column stands on).

## Layout

- `planning/new-project-checklist.md` — the original brain-dump checklist all the automation work derives from. Read this first for context on scope and rationale.
- `research/project-setup-automation-convo.md` — the prior conversation weighing primitives (scripts vs. hooks vs. MCP). Point-in-time rationale, not kept current.

## Conventions

- Research artifacts capture a point-in-time understanding; they are not automatically kept current.
- Planning documents are mutable and should be kept up to date as the project progresses.
